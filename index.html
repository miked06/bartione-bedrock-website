Everything Baritone does

One bot. Every way to get there.

The pathfinder, the movements, the processes and the settings follow Baritone's Java code closely — if you know Baritone, you already know this.

Pathfinding

A* over the real world with Baritone's moves: sprint, jump, parkour (even diagonally), pillar, fall, ladders, swimming — breaking and placing blocks on the way. Long trips run in segments through a long-distance chunk cache.

#goto 1000 64 -300

Mining

Finds ores in loaded chunks and in the cache, mines them and picks up the drops. No ore in sight? It goes down to the right level and branch-mines — in the overworld and the nether.

#mine 32 diamond

Building

Builds .mcstructure, .schem, .litematic and .schematic files, with stairs, logs and slabs facing the right way. Boxes, walls, spheres and cylinders with #sel.

#build castle.schem

Elytra flight

Plans a 3D flight, steers by simulating the elytra physics, fires rockets when it needs speed, swaps a worn elytra and lands safely on solid ground.

#elytra 5000 -2000

Farming

Harvests ripe crops, replants, uses bone meal on young ones and picks everything up — wheat, carrots, potatoes, beetroot, nether wart, cocoa.

#farm 32

Water bucket clutch

Falls of up to 20 blocks are planned with a water bucket: the water goes down a split second before the ground, and back into the bucket after.

allowWaterBucketFall

Follow & explore

Follow players or mobs, explore unseen chunks in a spiral, tunnel, go to the surface, walk to what you click up to 512 blocks away.

#follow player Steve

Waypoints

Per-world waypoints with tags, plus automatic death and bed waypoints. #home is always one command away.

#wp goto death

Drawn in the world

The path, the goal, the blocks to break and place and your selections are rendered with the game's own renderer, in Baritone's colors.

renderPath true

Chat control

Just type it in the chat

Commands start with #, run locally and are never sent to the server. They are Baritone's commands, with the same names and arguments.

  • #goto x y zwalk anywhere, or to the closest block of a type
  • #mine [n] <block>mine ores and pick up the drops
  • #build <file>build a schematic
  • #sel hsphere glasshollow sphere in a selection
  • #follow player <name>follow a player
  • #elytra x zfly there with fireworks
  • #set <setting> <value>any Baritone setting

Under the hood

Plays like a player would

The DLL lives inside the game. It reads the world, thinks on its own thread, and acts only through the inputs a player has — so the server just sees someone playing.

  1. 1

    Read

    Every tick, the chunks around you are copied into a snapshot. Chunks you leave are packed into a 2-bit long-distance cache saved on disk.

  2. 2

    Think

    Baritone's A* plans on a worker thread, over the snapshot and the cache, with costs measured in game ticks.

  3. 3

    Move

    Each movement decides which keys to hold, where to look and which block to break or place — like Baritone's PathExecutor.

  4. 4

    Act

    Simulated key presses, mouse clicks and camera rotation, and the game's own block-breaking calls. No packets crafted by hand.

Get started

Running in two minutes

  1. 1

    Download

    Get BaritoneBedrock.dll from the latest release, or build it yourself.

  2. 2

    Open a world

    Start Minecraft Bedrock 26.52 and turn off "Pause game when focus is lost" in the settings.

  3. 3

    Inject

    Inject the DLL into Minecraft.Windows.exe with any DLL injector. The chat says [Baritone] when it is ready.

  4. 4

    Play

    Type #help in the chat. #stop stops everything, #unload removes the bot.

Bots can be against the rules of multiplayer servers. Baritone Bedrock is meant for singleplayer worlds and servers that allow it. Use it at your own risk.

FAQ

Questions

Which Minecraft versions are supported?

Minecraft Bedrock 26.52 for Windows (package 1.26.5203.0). The DLL reads the game's memory directly, so each game update needs updated signatures and offsets — the development guide explains how, and contributions are very welcome.

Is it the same as Baritone for Java?

It is a port of Baritone's Java code: same commands, same settings, same algorithms and costs. A few things work differently on Bedrock (for example the elytra cannot predict terrain from the world seed) — they are all listed in PARITY.md.

Does it need a resource pack, a behavior pack or a server plugin?

No. It is a single DLL injected into the game. It works in singleplayer and, as a client-side bot, on servers.

My antivirus flags the DLL. Is it safe?

DLL injectors and injected DLLs are often flagged because of how they work. The code is open source: you can read it and build the DLL yourself with Visual Studio.

Does it work on consoles, phones or the Java Edition?

Only Minecraft Bedrock for Windows (x64). For Java Edition, use the original Baritone.

Something does not work. Where do I report it?

Check the troubleshooting guide, then open an issue with your log.txt.
